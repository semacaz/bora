## Deploy to Vercel
1. Create a GitHub repository and upload all files/folders from this project.
2. In Vercel choose **Add New → Project** and import the repository.
3. Deploy. This is a static HTML/CSS/JS site; no build command is needed.
4. Check the preview on desktop and phone before sharing.
